    REST API Documentation

    Overview

    The document processing system exposes a REST API for document classification and information extraction. The API is built using Flask and provides endpoints for single document processing, batch processing, and model management.

    Base URL

    http://localhost:5002/api/v1

    Authentication

    All API endpoints require authentication using a JWT token:

    curl -H "Authorization: Bearer <token>" http://localhost:5002/api/v1/...

    Endpoints

    1. Document Classification

    Classify Single Document

    POST /classify

    Request Body: 

    {
    "document": {
        "text": "Document text content",
        "metadata": {
            "source": "file_upload",
            "filename": "document.pdf"
        }
    }
}

    Response: 

    {
    "status": "success",
    "result": {
        "category": "invoice",
        "confidence": 0.95,
        "processing_time": 0.25
    }
}

    Batch Classification

    POST /classify/batch

    Request Body: 

    {
    "documents": [
        {
            "text": "Document 1 text",
            "metadata": {
                "source": "file_upload",
                "filename": "doc1.pdf"
            }
        },
        {
            "text": "Document 2 text",
            "metadata": {
                "source": "file_upload",
                "filename": "doc2.pdf"
            }
        }
    ]
}

    Response: 

    {
    "status": "success",
    "results": [
        {
            "document_id": "doc1",
            "category": "invoice",
            "confidence": 0.95
        },
        {
            "document_id": "doc2",
            "category": "receipt",
            "confidence": 0.88
        }
    ]
}

    2. Information Extraction

    Extract Fields from Document

    POST /extract

    Request Body: 

    {
    "document": {
        "text": "Document text content",
        "category": "invoice",
        "metadata": {
            "source": "file_upload",
            "filename": "document.pdf"
        }
    }
}

    Response: 

    {
    "status": "success",
    "result": {
        "fields": {
            "invoice_number": {
                "value": "INV-2023-001",
                "confidence": 0.98
            },
            "invoice_date": {
                "value": "2023-01-15",
                "confidence": 0.95
            },
            "total_amount": {
                "value": "$1,234.56",
                "confidence": 0.99
            }
        },
        "processing_time": 0.35
    }
}

    Batch Extraction

    POST /extract/batch

    Request Body: 

    {
    "documents": [
        {
            "text": "Document 1 text",
            "category": "invoice",
            "metadata": {
                "source": "file_upload",
                "filename": "doc1.pdf"
            }
        },
        {
            "text": "Document 2 text",
            "category": "receipt",
            "metadata": {
                "source": "file_upload",
                "filename": "doc2.pdf"
            }
        }
    ]
}

    Response: 

    {
    "status": "success",
    "results": [
        {
            "document_id": "doc1",
            "fields": {
                "invoice_number": {
                    "value": "INV-2023-001",
                    "confidence": 0.98
                }
            }
        },
        {
            "document_id": "doc2",
            "fields": {
                "receipt_number": {
                    "value": "REC-2023-001",
                    "confidence": 0.95
                }
            }
        }
    ]
}

    3. Model Management

    Get Model Status

    GET /models/status

    Response: 

    {
    "status": "success",
    "models": {
        "classification": {
            "current_model": "transformer",
            "version": "1.0.0",
            "last_trained": "2023-01-15T10:30:00Z"
        },
        "extraction": {
            "current_model": "hybrid",
            "version": "1.0.0",
            "last_trained": "2023-01-15T10:30:00Z"
        }
    }
}

    Train New Model

    POST /models/train

    Request Body: 

    {
    "model_type": "classification",
    "model_name": "transformer",
    "parameters": {
        "learning_rate": 2e-5,
        "batch_size": 32,
        "epochs": 3
    }
}

    Response: 

    {
    "status": "success",
    "job_id": "train_123",
    "message": "Training started"
}

    Get Training Status

    GET /models/train/{job_id}

    Response: 

    {
    "status": "success",
    "job_status": "completed",
    "metrics": {
        "accuracy": 0.95,
        "f1_score": 0.94
    }
}

    Error Handling

    Error Responses

    All error responses follow this format: 

    {
    "status": "error",
    "code": "ERROR_CODE",
    "message": "Error description"
}

    Common Error Codes

    • AUTH_ERROR: Authentication failed
    • INVALID_REQUEST: Invalid request format
    • PROCESSING_ERROR: Error during document processing
    • MODEL_ERROR: Error with model prediction
    • TRAINING_ERROR: Error during model training

    Rate Limiting

    The API implements rate limiting: - 100 requests per minute for authenticated users - 10 requests per minute for unauthenticated users

    Rate limit headers: 

    X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1623456789

    Python Client Example

    from document_processor_client import DocumentProcessorClient

# Initialize client
client = DocumentProcessorClient(
    base_url="http://localhost:5002/api/v1",
    api_key="your_api_key"
)

# Classify document
result = client.classify_document(
    text="Document text content",
    metadata={"filename": "document.pdf"}
)

# Extract fields
fields = client.extract_fields(
    text="Document text content",
    category="invoice",
    metadata={"filename": "document.pdf"}
)

# Batch processing
batch_results = client.process_batch([
    {"text": "Doc 1", "category": "invoice"},
    {"text": "Doc 2", "category": "receipt"}
])

    WebSocket API

    For real-time processing:

    const ws = new WebSocket('ws://localhost:5002/api/v1/ws');

ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    console.log('Received:', data);
};

ws.send(JSON.stringify({
    action: 'classify',
    data: {
        text: 'Document text content'
    }
}));
